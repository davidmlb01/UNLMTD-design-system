Política de Privacidade

Última atualização: julho de 2026

1. Responsável pelo tratamento

A UNLMTD Co Produções Ltda, inscrita no CNPJ sob o número 33.838.440/0001-71, com sede em São Paulo, SP, Brasil, é a responsável pelo tratamento dos dados pessoais coletados neste site (unlmtd.etc.br) e nos produtos desenvolvidos pela empresa, incluindo o Destaka (destaka.com.br).

Contato: contato@unlmtd.etc.br

2. Dados coletados neste site

O site unlmtd.etc.br é um site institucional informativo. Coletamos apenas:

  • Dados de navegação básicos (via logs do servidor): endereço IP, páginas acessadas, data e hora.
  • Dados de contato fornecidos voluntariamente (nome e e-mail, se utilizado).

Para a política de privacidade do produto Destaka, acesse destaka.com.br/privacy.

3. Como usamos os dados

  • Responder solicitações de contato e informações comerciais.
  • Análise de desempenho do site para melhoria da experiência.
  • Cumprimento de obrigações legais.

4. Google APIs e dados de terceiros (produto Destaka)

O produto Destaka, desenvolvido pela UNLMTD, utiliza a Google Business Profile API para acessar e gerenciar dados de perfis do Google em nome dos usuários que autorizam expressamente esse acesso via OAuth 2.0.

O uso dos dados obtidos via Google APIs pelo Destaka obedece à Política de Dados de Usuários de Serviços de API do Google, incluindo os requisitos de Uso Limitado (Limited Use).

  • Dados acessados: informações do Google Business Profile (avaliações, posts, dados de localização e métricas de desempenho) do perfil autorizado pelo próprio usuário.
  • Finalidade exclusiva: os dados são usados somente para executar as funcionalidades contratadas pelo usuário dentro do Destaka. Não são usados para publicidade, perfis de terceiros ou qualquer finalidade além da autorizada.
  • Armazenamento: tokens OAuth e dados são armazenados com criptografia. Tokens são revogados imediatamente ao cancelamento da conta.
  • Compartilhamento: dados obtidos via Google APIs não são compartilhados, vendidos ou transferidos a terceiros.
  • Acesso humano: nenhum funcionário acessa dados de Google Business Profile de usuários individualmente, exceto para suporte técnico explicitamente solicitado pelo titular.

A política de privacidade completa do Destaka, com todos os detalhes de tratamento de dados do produto, está disponível em destaka.com.br/privacy.

5. Base legal (LGPD)

  • Art. 7º, V — Execução de contrato: para responder solicitações de contato e executar serviços contratados.
  • Art. 7º, I — Consentimento: para acesso a dados de Google Business Profile via OAuth 2.0 (consentimento explícito do titular no momento da autorização).
  • Art. 7º, IX — Legítimo interesse: para análise de desempenho do site.

6. Compartilhamento de dados

Não compartilhamos, vendemos ou alugamos seus dados pessoais com terceiros, exceto quando necessário para cumprimento de obrigação legal ou ordem judicial. Dados obtidos via Google APIs nunca são compartilhados com terceiros.

7. Retenção de dados

Dados de contato são mantidos por até 2 anos ou até o pedido de exclusão. Logs de servidor são mantidos por até 90 dias. Dados de Google Business Profile são mantidos enquanto a conta estiver ativa e excluídos em até 30 dias após o cancelamento.

8. Seus direitos

Nos termos da LGPD (Lei 13.709/2018), você pode solicitar:

  • Acesso aos dados pessoais que mantemos sobre você.
  • Correção de dados incorretos.
  • Exclusão dos dados pessoais.
  • Revogação do consentimento e desconexão de APIs autorizadas.
  • Informação sobre compartilhamento de dados.

Para exercer esses direitos: contato@unlmtd.etc.br

9. Cookies

Este site não utiliza cookies de rastreamento ou publicidade. Podem ser utilizados cookies técnicos essenciais para o funcionamento do site.
