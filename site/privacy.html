Política de Privacidade

Última atualização: junho de 2025

1. Responsável pelo tratamento

A UNLMTD Co Producoes Ltda, inscrita no CNPJ sob o número 33.838.440/0001-71, com sede em São Paulo, SP, Brasil, é a responsável pelo tratamento dos dados pessoais coletados neste site (unlmtd.etc.br) e nos produtos desenvolvidos pela empresa, incluindo o Destaka (destaka.com.br).

Contato: contato@unlmtd.etc.br

2. Dados coletados neste site

O site unlmtd.etc.br é um site institucional informativo. Coletamos apenas:

  • Dados de navegação básicos (via logs do servidor): endereço IP, páginas acessadas, data e hora.
  • Dados de contato fornecidos voluntariamente (nome e e-mail via formulário de contato, se utilizado).

Para a política de privacidade do produto Destaka, acesse destaka.com.br/privacy.

3. Como usamos os dados

  • Responder solicitações de contato e informações comerciais.
  • Análise de desempenho do site para melhoria da experiência.
  • Cumprimento de obrigações legais.

4. Base legal (LGPD)

  • Art. 7º, V — Execução de contrato: para responder solicitações de contato.
  • Art. 7º, IX — Legítimo interesse: para análise de desempenho do site.

5. Compartilhamento de dados

Não compartilhamos, vendemos ou alugamos seus dados pessoais com terceiros, exceto quando necessário para cumprimento de obrigação legal ou ordem judicial.

6. Retenção de dados

Dados de contato são mantidos por até 2 anos ou até o pedido de exclusão. Logs de servidor são mantidos por até 90 dias.

7. Seus direitos

Nos termos da LGPD (Lei 13.709/2018), você pode solicitar:

  • Acesso aos dados pessoais que mantemos sobre você.
  • Correção de dados incorretos.
  • Exclusão dos dados pessoais.
  • Informação sobre compartilhamento de dados.

Para exercer esses direitos: contato@unlmtd.etc.br

8. Cookies

Este site não utiliza cookies de rastreamento ou publicidade. Podem ser utilizados cookies técnicos essenciais para o funcionamento do site.
